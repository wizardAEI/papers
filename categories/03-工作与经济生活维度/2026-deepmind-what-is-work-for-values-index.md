# 工作究竟为了什么？AI时代的劳动、政治与意义："工作价值指数"四国调查

- **来源**: 《What is Work For? Labor, Politics, and Meaning in the Age of AI》，arXiv预印本（DeepMind Institute；调研执行机构More in Common）
- **日期**: 调研执行于2026年6-7月；论文发表于2026年10月；DeepMind Institute同步发布配套文章，2026年11月2日引发媒体广泛报道
- **链接**: https://arxiv.org/abs/2610.39375 ；https://institute.deepmind.com/essays/what-is-work-for-human-wellbeing-and-the-value-of-work-in-the-agi-era/
- **类目**: 工作与经济生活维度

## 摘要

More in Common对丹麦、印度、英国、美国四国共8,234名工作年龄成年人开展的代表性配额抽样调查（按年龄、性别、教育、地区配额），首次构建"工作价值指数"(Work Values Index) 框架，将劳动者在非金钱层面对工作的依恋划分为四种画像，并系统考察这些非金钱工作动机在AI经济转型政策设计（尤其是全民基本收入）中的含义。该研究是本目录迄今样本量最大、首次采用正式心理测量工具量化"工作的非金钱意义"、并将其与具体AI转型政策选项直接挂钩的跨国研究。

## 关键发现

- **四种工作价值画像，内在动机型占比最高**：在可分类的6,224名受访者中，33.21%属于"内在动机型"（因工作本身的意义、学习机会、社会贡献感而重视工作）；26.29%属于"交易型"（主要看重薪酬福利）；23.12%属于"社群导向型"（看重同事归属感与社交机会）；17.38%属于"地位驱动型"（看重工作带来的认可与社会地位）——这意味着仅略多于四分之一的劳动者主要因"金钱"本身而工作，近四分之三的劳动者将非金钱因素列为首要工作动机。
- **基本收入可能无法完全补偿工作的非金钱价值**：在一项假设性选择实验中，约20%的7,106名在职受访者即便被提供相当于当前薪资120%的保障性收入（同时保留医疗、养老金与带薪休假），仍然选择不会离开现有工作；内在动机型劳动者拒绝基本收入替代方案的比例尤其高，且这些非金钱工作动机在不同收入水平与白领/蓝领职业类别间分布均衡——这一发现对"全民基本收入足以应对AI导致的大规模结构性失业冲击"这一政策直觉提出了直接的实证挑战：收入保障可以替代工资，但未必能替代工作提供的意义感、社会归属与身份认同。
- **AI就业风险感知的职业分化**：在在职劳动者中，37.2%认为AI或自动化在未来十年内"确定/非常可能/有些可能"取代自己的工作，其中白领劳动者的比例（40.4%）显著高于体力/服务业劳动者（28.8%）——该比例衡量的是主观风险感知而非已实现的失业规模或岗位流失的因果估计，与本目录持续强调的"担忧上升速度持续超过实际岗位流失速度"判断保持一致的方法论审慎性。
- 整体满意度基准：81%的受访者表示对当前工作感到满意，且这一比例在白领与蓝领、不同收入群体间高度一致，表明"重视工作非金钱价值"并非某一特定阶层的专属现象，而是跨越职业与收入结构的普遍心理模式。

## 与本维度的关联

这项研究首次为本目录持续讨论的"AI转型政策应对方案"（基本收入、再培训补贴等）提供了来自非金钱工作动机角度的审慎提醒——此前收录的多项研究（Elon大学《工作意义》调研、CGK高管焦虑调研）已从"主观担忧"层面揭示工作意义感正受到AI冲击的威胁，而本研究则进一步将这一威胁与具体政策工具（基本收入）的实际补偿能力直接挂钩，提出一个此前未被充分讨论的政策设计盲点：若AI转型政策仅聚焦于"收入替代"而忽视工作提供的意义、社群归属与身份认同等非金钱价值，可能无法真正缓解劳动者因AI转型而产生的深层焦虑与抵触情绪，即便收入保障本身在经济学意义上已经"足够慷慨"。这一发现与本维度持续强调的"瓶颈可能不在于技术本身，而在于组织/制度设计是否充分考虑人的多维度需求"这一核心判断形成呼应，并首次将该判断从"企业组织设计"层面扩展至"国家宏观转型政策设计"层面。
