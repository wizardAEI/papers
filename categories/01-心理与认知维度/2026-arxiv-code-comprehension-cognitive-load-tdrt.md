# 感觉更轻松，实则更费力：AI辅助代码理解中的认知负荷

- **来源**: arXiv 预印本（科罗拉多州立大学计算机科学系×心理学系，White, Rose, Buckman, McDonnell, Ortega, Trinkenreich）
- **日期**: 2026年11月（arXiv:2611.12019）
- **链接**: https://arxiv.org/abs/2611.12019
- **类目**: 心理与认知维度

## 摘要

一项3×2被试内实验，招募20名计算机科学新手学生，在有/无生成式AI辅助的条件下阅读不同长度的Java代码片段，随后完成无AI辅助的理解测验。研究首次将触觉侦测反应任务（tactile Detection-Response Task, tDRT）这一低成本、ISO标准化的客观认知负荷测量工具引入软件工程研究领域，用以替代依赖事后回忆的NASA-TLX主观量表与昂贵的EEG/fNIR/眼动等生理测量手段。

## 关键发现

- **AI辅助显著提升客观认知负荷，但主观感受无变化**：AI辅助使tDRT反应时间升高11.2%（阅读与测验阶段均如此），但参与者填写的主观工作负荷量表（NASA-TLX、SEQ）未显示出相应变化——这是本目录"氛围编程悖论"（EEG证据）研究之后，再次以独立、更低成本的客观生理测量方法证实"开发者无法准确感知自己在管理AI工具时实际消耗的认知资源"这一核心现象。
- **负荷升高效应持续到AI移除之后**：在不可使用AI的测验阶段，此前接受过AI辅助的参与者反应时间仍比对照组高6.93%（p=.007），表明AI辅助带来的认知负荷并非仅限于"双任务并行"期间，而存在某种程度的滞后效应。
- **理解质量未见显著提升**：在本研究评估的难度范围内，AI辅助未能证明可以改善代码理解测验得分（得分普遍接近满分，限制了检测硬任务收益的统计效力）。
- **信任呈条件化模式**：参与者对AI的信任并非一次性评价，而是依代码复杂度动态调整——简单代码直接采信AI解释，复杂代码则会将AI输出与自行阅读交叉验证；部分参与者的阅读策略逐渐转向"略读代码本身、精读AI解释"。

## 与本维度的关联

本研究将已收录的"氛围编程悖论"（EEG证据，专业开发者使用智能体AI编程）证据场景进一步扩展至"代码理解/阅读"这一更基础、更高频的软件工程日常任务，且研究对象换为新手学生而非专业开发者，使用的客观测量工具（tDRT）成本远低于EEG，具备更强的可推广性。两项研究共同证实：无论是"生成代码"还是"阅读代码"，无论是专业开发者还是初学者，生成式AI辅助下的"主观轻松感"与"客观认知负荷"存在系统性背离，且这种背离本身难以被使用者自我察觉，进一步印证本目录持续强调的"认知卸载的负面效应具有跨场景、跨人群的一般性"这一判断。
